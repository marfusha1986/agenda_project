# Minimalist Personal Agenda & Task Tracker

Python teknolojileri kullanılarak geliştirilmiş, modern ve minimalist bir kişisel ajanda ve görev takip masaüstü uygulamasıdır. Proje; **PySide6** masaüstü grafik arayüzüne (GUI), yüksek performanslı bir **FastAPI** arka ucuna ve **Oracle Veritabanı** kalıcı depolama katmanına sahiptir.

Gerçek bir takvim-ajanda iş akışıyla tasarlanmıştır; kullanıcıların görevleri görsel olarak takip etmesine, interaktif bir takvimle sorunsuz senkronize olmasına ve entegre erteleme takip sistemi sayesinde görev disiplinini korumasına olanak tanır.

---

## 🚀 Temel Özellikler

* **İnteraktif Takvim Entegrasyonu:** `QCalendarWidget` ile görev son tarihleri arasında gerçek zamanlı senkronizasyon. Aktif görevi olan tarihler takvim üzerinde otomatik olarak vurgulanır.
* **Disiplin ve Erteleme Sayacı:** Verimliliği ve alışkanlık takibini teşvik etmek için bir görevin kaç kez ertelendiğini (`postpone_count`) takip eder.
* **Modern Masaüstü Arayüzü (PySide6):** Akıcı görev erteleme işlemleri için özel tarih seçici diyaloglarına sahip, temiz ve duyarlı arayüz.
* **RESTful API Arka Ucu (FastAPI):** Kapsamlı CRUD işlemlerini, dinamik tarih işlemeyi ve Oracle DB bağlantısını yönetir.
* **Kalıcı Depolama (Oracle Free DB):** Görevleri ve meta verileri güvenli bir Oracle Docker kapsayıcısında saklar.

⚙️ Kurulum ve Yapılandırma
1. Ön Koşullar
Python 3.10+

Docker (Oracle Veritabanı kapsayıcısını çalıştırmak için)

2. Depoyu Kopyalayın (Clone)
Bash
git clone [https://github.com/marfusha1986/agenda_project.git](https://github.com/marfusha1986/agenda_project.git)
cd agenda_project
3. Sanal Ortam ve Bağımlılıkları Kurun
Bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
4. Veritabanı Kurulumu (Docker ile Oracle DB)
Oracle Free kapsayıcınızın çalıştığından emin olun ve disiplin sayacı sütununu içeren tasks tablosunu oluşturun:

SQL
CREATE TABLE tasks (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title VARCHAR2(255) NOT NULL,
    due_date DATE,
    postpone_count NUMBER DEFAULT 0
);
🏃‍♂️ Uygulamayı Çalıştırma
Adım 1: FastAPI Arka Ucunu Başlatın
Terminalinizde (sanal ortam aktifken):

Bash
cd backend
uvicorn main:app --reload
(Arka uç http://127.0.0.1:8000 adresinde çalışacaktır)

Adım 2: PySide6 Masaüstü Arayüzünü Başlatın
Ayrı bir terminal penceresi/sekmesi açın, sanal ortamınızı etkinleştirin ve şunu çalıştırın:

Bash
python frontend/app.py
📌 Kullanım İş Akışı
Görevleri Görüntüleme: Sağ listede planlanan görevleri anında görmek için sol taraftaki takvimde herhangi bir güne tıklayın.

Görevleri Erteleme: Bir görev seçin, "Ertele (+1 Gün)" düğmesine tıklayın, interaktif takvim diyalog penceresinden yeni bir hedef tarih seçin ve takvimi güncelleyin.

Disiplin Takibi: Her erteleme işlemi görevin sayacını otomatik olarak artırır ve sık ertelenen görevler için görsel uyarılar sağlar.
